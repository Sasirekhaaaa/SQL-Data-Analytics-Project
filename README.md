# Zepto-E-Commerce-Data-Analysis-SQL
## Project Overview
This project focuses on analyzing Zepto e-commerce data using SQL and MySQL. 
The objective is to explore product pricing, discounts, availability, and other 
product-related information to generate useful business insights.
## Project Objective
To use SQL queries to analyze e-commerce product data and extract meaningful 
insights that can support data-driven business decisions.
## Tools & Technologies
- MySQL
- SQL
- MySQL Workbench
## Key SQL Concepts Used
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- DISTINCT
- LIKE
- Aggregate Functions
- UPDATE
- DELETE
- Filtering and Sorting
## Analysis Performed
- Analyzed product prices and discounted prices
- Calculated and compared discount percentages
- Identified products based on pricing and availability
- Used filtering and sorting to extract relevant products
- Performed data analysis using SQL queries
## Conclusion
The project provided practical experience in SQL data analysis and helped 
understand how SQL can be used to transform raw e-commerce data into useful 
business insights.
